# ⚔️ Código Ancestral

> *"Lo clásico y lo moderno forjados en un solo repositorio. El HTML es mi cimiento, el CSS mi armadura, el JavaScript mi alma y Angular mi imperio. Aquí yacen todos los proyectos que construí en VS Code; mi legado para el mundo, organizado por carpetas como un gran libro de hechizos."*

---

## 📜 Índice del Grimorio

Este repositorio está dividido en dos grandes reinos:

- **🏛️ `/vanilla/`** → Los rituales puros. Proyectos con HTML, CSS y JavaScript sin frameworks. La base de todo.
- **⚡ `/angular/`** → La arquitectura moderna. Aplicaciones Single Page Application (SPA) construidas con el poder de TypeScript y Angular.
